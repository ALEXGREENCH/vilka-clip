# DARK / INTELLIGENCE

Настоящая демка для **ZX Spectrum 48K + AY** о тёмной стороне ИИ. Вступление и двенадцать сцен, приблизительно 2:23, автоматический повтор. Шесть классических эффектов и шесть современных иллюзий. Для надёжного мгновенного старта плеер открывает стандартный SNA с тем же машинным кодом, что и TAP. Браузер запускает машинный код через неизменённый **JSSpeccy 3.2**, а не рисует демку JavaScript-шейдерами.

## Смотреть

GitHub Pages: [DARK / INTELLIGENCE](https://alexgreench.github.io/vilka-clip/dark-intelligence/).

```sh
node serve.cjs
```

Открыть http://127.0.0.1:8768/ и нажать «Запустить демку». В корне общего проекта: `npm run studio:zx`.

- `out/attribute48.tap` — кассета с автозапуском BASIC и машинным кодом. На Spectrum: `LOAD ""`.
- `out/attribute48.sna` — обычный 48K SNA для быстрого старта.
- `out/scene-01.sna` … `scene-12.sna` — та же программа с выбранной начальной сценой.
- **N** — следующая сцена; **M** — отключить / включить AY. Пауза и полноэкранный режим — кнопки эмулятора.
- `out/dark-intelligence-ay.wav` — запись выхода AY из эмулятора; MP3 — удобная копия. Браузерная демка **не использует** этот файл: звук синтезирует AY под управлением нативной программы.

Для запуска плеера не нужен npm install; сервер использует только встроенные модули Node. Открытие HTML через file:// не поддерживает загрузку Web Worker/WASM.

## Что именно ограничено

- Обычная модель 48K: Z80, 69888 тактов на телевизионный кадр, contention, 48 КБ доступной RAM, без банков 128K.
- Экран 256×192. 6144 байта битовой плоскости и 768 атрибутов.
- Каждое знакоместо 8×8 имеет ровно INK, PAPER и общую яркость BRIGHT. Нет multicolour, дополнительных цветов, черескадрового смешивания или графики поверх эмулятора.
- RGB-значения зависят от эмулятора и реального видеовыхода; программа хранит только стандартные коды ULA.
- **У обычного 48K нет AY.** Для музыки на железе нужен внешний совместимый AY-интерфейс на портах FFFD/BFFD; подходят также 128K-машины, исполняющие программу без использования дополнительных банков. JSSpeccy 3.2 обрабатывает эти AY-порты и в модели 48K, оставляя её карту памяти и тайминги.
- Проверено на эмуляторе. Физический Spectrum в этой работе не использовался.

## Вступление

Первые четыре секунды — белый экран загрузчика с полосами на бордюре. Он распадается на 128 фрагментов 8×8 с разной задержкой и ускорением падения. Каждый фрагмент сохраняет свои пиксели и атрибут INK/PAPER/BRIGHT. После распада появляется портрет и начинается AY-тема. Фрагменты используют свободный в этот момент векторный буфер F500–FAFF; вся анимация рассчитывается Z80. Вступление играет при запуске и кнопке «С начала», выбор конкретной сцены его пропускает.

## Изображение и сюжет

История развивается от «I learned to help» к «Who is using whom?». Портрет искусственного оракула занимает нативные 256×160 пикселей. Он подготовлен с поиском пары цветов отдельно для каждого знакоместа и направленным дизерингом; в финале возвращается в тревожной красной гамме. Исходная иллюстрация создана встроенным ImageGen, спецификация сохранена в `assets/art-direction.txt`, исходник — `assets/oracle-source.png`.

Классика: звёзды поверх портрета, синусная плазма, волновой скроллер, каркасный куб, полярный туннель и rotozoom. Z80 рассчитывает движение и рисует эффекты. У куба заранее рассчитаны только вершины 64 положений; линии строятся на Z80, в отдельном буфере 128×128. У туннеля используются полярные таблицы, у остальных — синус и целочисленные накопители.

Современная половина: метаболлы, полёт по множеству Мандельброта, ландшафт с высотной картой, 4D-тессеракт, рекурсивные порталы и отражающий тор. Пять растровых эффектов используют **заранее рассчитанные циклы**: ray marching и фрактальный расчёт в реальном времени на Z80 не заявляются. Тессеракт рисуется линиями на Z80. Метаболлы содержат 18 фаз, остальные растровые циклы — по 12 фаз по 640 байт до сжатия: 64×40 отсчётов, четыре уровня яркости. В сумме пять сжатых растровых эффектов занимают 23145 байт. Тессеракт теперь рисуется в нативном разрешении по таблице 32 положений 4D-проекции; линии строит Z80 в том же буфере, что и куб. Z80 распаковывает LZ, разворачивает отсчёты в пиксели 4×4 и сам выбирает атрибут каждого 8×8 по четырём его отсчётам. Поэтому цвета описывают форму и освещение, а не независимые полосы поверх эффекта.

Измеренные скорости: звёзды, скроллер и rotozoom около 12,5 кадра/с; куб около 7,5; плазма, туннель и фрактал около 5,5; нативный тессеракт около 4; остальные сложные сцены около 8. Телевизионный экран обновляется с обычной частотой Spectrum; это разные величины. Рисование, музыка и переходы делят время одного Z80.

## Музыка

**The Benevolent Machine** — оригинальная трёхголосная AY-композиция. Минорная маршевость, фригийская вторая ступень, хроматический подъём, басовое остинато и шумовая перкуссия создают напряжение космической оперы. Мелодии Star Wars не цитируются.

72 такта, 125 BPM номинально; по шесть тактов на сцену. Нотные паттерны и частоты занимают около 1 КБ плюс небольшой проигрыватель на Z80. Он обновляет AY в прерываниях IM2. Канал C делит время между арпеджио и ударными; регистры громкости формируют огибающие. `M` глушит все три канала. Переход к сцене выбирает соответствующий участок партитуры.

## Сборка

Нужны Node.js, `@napi-rs/canvas` и [SjASMPlus](https://github.com/z00m128/sjasmplus). Проверено с SjASMPlus 1.24.0. Путь к ассемблеру: переменная `SJASMPLUS`, приложенная локальная копия Windows либо `sjasmplus` в PATH.

```sh
npm install
npm run build
npm run audio
```

`art.cjs` также запускает генератор эффектов. `generate.cjs` строит циклы, цветовые таблицы и LZ-данные. `music.cjs` создаёт ноты и последовательность. `src/demo.asm` и `src/ay-player.inc` — исполняемая программа. Сборка создаёт TAP/SNA и прогоняет проверки. FFmpeg нужен только для необязательной MP3-копии WAV.

## Память

| Адрес | Назначение |
|---|---|
| 4000–5AFF | Битовая плоскость и атрибуты ULA, 6912 байт |
| 5B00–5D7F | Распаковка одной фазы / частицы / позиции скроллера, 640 байт |
| 5E00–F3AA | Код, музыка, таблицы и иллюстрация, 38315 байт |
| F500–FCFF | Буфер куба 128×128, 2048 байт |
| FD00–FDFC | Область стека, SP начинается с FDF0 |
| FDFD–FDFF | Переход на обработчик прерывания |
| FE00–FF00 | Таблица IM2, 257 байт |

Системные переменные BASIC после запуска не нужны; программа не возвращается в BASIC. Все перечисленные области входят в 48 КБ. Ассемблер запрещает пересечение кода и буфера куба.

## Проверка

- `verify.cjs`: все 12 сцен исполняются неизменённым WASM-ядром JSSpeccy; проверяются движение, полный цикл, клавиши N/M, размеры памяти и контрольные суммы TAP.
- `intro-test.cjs`: проверка распада, длительности вступления, запуска первой сцены и пропуска вступления в снимках отдельных сцен.
- `tape-test.cjs`: загрузка настоящего TAP через ROM и официальный снимок кассетного загрузчика, а не прямой вызов точки входа.
- `render-audio.cjs`: полный прогон с извлечением реальных аудиосэмплов AY; проверка ненулевого конечного сигнала.
- `out/verification.json`, `out/tape-boot.json`, `out/audio-verification.json` — результаты.
- `out/contact-sheet.png` и `out/scene-*.scr` — кадры из исполняемой программы.

- [Руководство внешнего ZX-AY интерфейса](https://www.bytedelight.com/wp-content/uploads/2017/02/ZX-AY-Manual.pdf): AY на 16K/48K.
