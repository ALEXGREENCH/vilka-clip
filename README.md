# Вилка

Интерактивный музыкальный клип для GitHub Pages: 58 сюжетных планов, 32 визуальных стиля, 255 секунд (4:15).

Визуальные сцены, анимация и эффекты создаются кодом Canvas и WebGL во время воспроизведения. Готовые видеокадры и MP4 для работы сайта не нужны. Песня хранится отдельно в `assets/song.mp3`; тайминг текста и огибающая звука — в `timeline.json` и `out/energy.json`.

Каталог готов к публикации на GitHub Pages: его содержимое должно находиться в корне публикуемого сайта, рядом с `index.html`. Все ссылки относительные, поэтому сайт работает и в подпапке репозитория.

Для локального просмотра подойдёт любой статический HTTP-сервер. Например, запустите в этой папке `python -m http.server 8080` и откройте адрес сервера в браузере. Нажмите «Смотреть», чтобы начать воспроизведение со звуком. Сборка приложения и серверная часть не требуются.

Права на песню сохраняются за её правообладателями. Этот README не предоставляет новой лицензии на музыку или другие медиаматериалы.
